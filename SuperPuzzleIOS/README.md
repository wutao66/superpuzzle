# Super Puzzle iOS

这是 SwiftUI 原生实现，使用仓库中的 `SuperPuzzle.xcodeproj` 打开并运行。视频播放与动态拼图使用系统 AVFoundation、Core Image 和单画布绘制，不需要额外依赖。

最低系统版本建议设为 iOS 16，以使用 `PhotosPicker`。不需要额外依赖或完整相册访问授权；系统相册选择器只提供用户选中的照片或视频。照片在内存中切片，视频使用临时文件，切换素材时删除。

## 规则

- 简单：9 片
- 普通：100 片
- 困难：300 片
- 噩梦：1000 片
- 地狱：2000 片

行列数会从目标片数的因数中按原图宽高比择优，因此拼图块不是强制正方形。长按拼图约 0.4 秒后可拖到另一块上，松手交换位置；也可依次点击两块交换。长按拾取时轻震一次，成功交换时再震一次；放回原位或拖出棋盘不会触发交换震动。触觉反馈需在支持的真机上体验。完成后自动停止计时。

点击「提示」会恢复棋盘全览，用金色边框和 ①② 标记建议交换的两块拼图，并显示行列位置与操作说明；交换后可让 ① 归位。优先提示当前选中的错位拼图，不会自动交换。交换或重新打乱后清除提示，完成拼图后禁用提示按钮。

## 视频拼图

- 相册入口支持照片和视频；导入期间显示进度，失败时显示错误说明。
- 视频预览和拼图页面均提供播放／暂停、可拖动进度条、当前时间／总时长与静音按钮。默认静音，开始视频拼图后播放，播放结束自动循环。
- 拖动进度条时暂停并预览定位后的画面，松手后恢复拖动前的播放状态；原本暂停的视频保持暂停。
- 所有难度共用一个播放器和一份视频帧，按每块的原始位置裁切并绘制；长按拖动、点击交换、提示和震动仍可使用。提示只高亮和说明，不自动移动拼图。
- 视频按拍摄方向显示，解码后的展示帧最长边限制为 1280 像素，最高 30 帧／秒。高片数视频的实际帧率和耗电仍需真机验证。
- 进入后台或返回素材选择页时暂停视频；替换素材或离开页面时释放播放资源。

## 完成庆祝

完成拼图后显示恭喜弹窗，固定展示本次用时、难度和片数，并给予鼓励。奖杯轻弹出现，彩纸短暂飘落后自动结束；开启系统「减少动态效果」时不播放这些动画。

点击「欣赏作品」关闭弹窗，点击「再来一局」重新打乱并从零计时。视频拼图在弹窗期间暂停，欣赏作品时恢复弹窗前的播放状态；完成时提供一次成功震动。

## 验证

`SuperPuzzleIOSTests/PuzzleCompletionTests.swift` 覆盖中英文用时格式、完成事件仅触发一次、完成后停止计时及重新开局。

`SuperPuzzleIOSTests/PuzzleVideoTests.swift` 使用本地生成的视频覆盖方向、暂停定位、连续定位请求、播放／暂停、拖动后恢复状态、静音状态、循环、资源释放、损坏文件、视频拼图提示不自动交换，以及碎片裁切和共享帧更新。可在 Xcode 中选择 SuperPuzzle scheme 执行测试。
