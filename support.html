使用帮助、设备支持与问题反馈Usage help, device support, and issue reporting

Super Puzzle 无需注册或联网。选择照片或视频、设定拼图片数，即可在 iPhone 或 iPad 上开始。Super Puzzle needs no account or network connection. Choose a photo or video, set the piece count, and start on iPhone or iPad.

如何开始拼图？How do I start a puzzle?

点击“选择照片或视频”，通过 Apple 系统选择器选取素材，再选择 9、100、300、1000 或 2000 片。Tap Choose a Photo or Video, select media with Apple's system picker, then choose 9, 100, 300, 1,000, or 2,000 pieces.

照片或视频无法导入Media will not import

请确认素材仍保存在设备上且能在“照片”App 中正常打开。对于只存于 iCloud 的素材，请先在“照片”中完成下载后重试。Confirm the item is available on the device and opens in Photos. If it exists only in iCloud, download it in Photos before trying again.

iPad 与多任务窗口iPad and multitasking

支持 iPad 横屏、竖屏、Split View 与 Stage Manager。改变窗口大小后，棋盘和控制区会自动调整；空间不足时可关闭侧栏或放大窗口。iPad portrait, landscape, Split View, and Stage Manager are supported. The board and controls adapt as the window changes; enlarge the window when more space is needed.

需要联网吗？Is internet required?

不需要。拼图处理完全在设备本地完成。App 没有账号、广告、分析或追踪服务，也不会上传你选择的素材。No. Puzzle processing happens entirely on your device. There are no accounts, ads, analytics, or trackers, and selected media is never uploaded.

支持哪些设备？Which devices are supported?

支持运行 iOS 16 或 iPadOS 16 及以上版本的 iPhone 和 iPad。较大的拼图会需要更多内存，旧设备建议先尝试较少片数。iPhone and iPad devices running iOS or iPadOS 16 and later are supported. Large puzzles use more memory, so older devices may work best with fewer pieces.

如何提供有效反馈？How should I report an issue?

请在 GitHub Issues 中写明设备型号、系统版本、照片或视频模式、拼图片数和复现步骤。请勿上传含有私人内容的原始素材。In GitHub Issues, include device model, OS version, photo or video mode, piece count, and reproduction steps. Do not upload private source media.
